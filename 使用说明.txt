图书漂流（共享借阅）平台 —— 项目骨架使用说明
============================================

【这是什么】
这是一个可以在 IDEA 中打开的空项目骨架：
- 目录结构、包、页面、配置文件全部齐全（符合项目说明文档的框架）
- 所有代码实现留空（标注了 TODO / 待填写）
- 五个人各自把自己负责的文件补上代码即可

【怎么打开】
1. 打开 IDEA → File → Open → 选中本文件夹下的 pom.xml（Maven 方式打开）
2. 等待依赖下载完成（需联网，首次较慢）
3. 配置 Tomcat：Run → Edit Configurations → + → Tomcat Server → Local（Tomcat 10.1）
   → Deployment 加 book-floating:war exploded
4. 启动后访问：http://localhost:8080/book_floating_war/

【目录结构与负责人提示】
src/main/java/com/book/
  entity/    实体类（User、Book）        ← 公共基础，组内统一后所有人共用
  filter/    过滤器（Encoding、Login）   ← F6、F7
  servlet/   Servlet（注册/登录/注销/列表/详情/收藏/上传）← F1-F5、选做F8
  listener/  监听器（初始化、在线人数）   ← 选做F9
src/main/webapp/
  WEB-INF/web.xml   配置文件（Filter、Listener 已配好）
  *.jsp             页面（7个，按功能补内容）
  static/css/js     样式与校验脚本

【注意】
- 代码是 Jakarta 版（import jakarta.servlet.*），适配 Tomcat 10，不要改回 javax
- 实体类、统一约定（session/application 的 key 名）先由组长定死，所有人照用
- 选做 F8 头像上传：需在 pom.xml 取消注释文件上传依赖，并补充 UploadServlet 的 import
- 骨架中的 TODO 全部完成后，项目即具备全部必做功能（F1-F7）
